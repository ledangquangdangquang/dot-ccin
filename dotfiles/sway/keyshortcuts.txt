SWAY — Mod is the Super/Windows key
────────────────────────────────────────────────────────────
Mod + i                 Show this shortcut list
Mod + Return            Open Foot terminal
Mod + e                 Open Nautilus file manager
Mod + Shift + f         Open Firefox
Mod + Shift + z         Open Zathura
Mod + Space             Open Fuzzel launcher
Mod + w                 Open Wi-Fi menu
Mod + Ctrl + b          Open Bluetooth menu
Mod + v                 Open clipboard history
Mod + Shift + v         Clear clipboard history
Mod + q                 Close focused window
Mod + Shift + r         Reload Sway config
Mod + Shift + e         Open power menu

NOTIFICATIONS AND SCREENSHOTS
────────────────────────────────────────────────────────────
Mod + n                 Close all notifications
Mod + Shift + n         Pop notification history
F8                      Capture region and open Satty
Shift + F8              Capture full screen and open Satty
Ctrl + F8               Capture region directly to clipboard

WINDOWS AND PANES
────────────────────────────────────────────────────────────
Mod + h / j / k / l     Focus left / down / up / right
Mod + Shift + h/j/k/l   Move window left / down / up / right
Mod + Ctrl + h/l        Shrink / grow window width
Mod + Ctrl + j/k        Shrink / grow window height
Mod + \                 Set master 70% / stack 30% layout
Mod + Shift + t         Toggle status bar

WORKSPACES
────────────────────────────────────────────────────────────
Mod + a/s/d/c/b         Go to workspace A/S/D/C/B
Mod + 1/2/3/4/5         Go to workspace 1/2/3/4/5
Mod + Shift + key       Move window to the matching workspace
Firefox                 Opens automatically on workspace B
Foot                    Opens automatically on workspace 1

HARDWARE
────────────────────────────────────────────────────────────
F1                      Toggle audio mute
F2 / F3                 Decrease / increase volume by 5%
F6 / F7                 Decrease / increase brightness by 5%
F9                      Toggle 4000K Night Light
Media brightness keys   Change brightness by 5%
Media volume keys       Change volume or toggle mute

TMUX — Prefix is Alt + a
────────────────────────────────────────────────────────────
Alt+a, c                Create a new window
Alt+a, s                Choose session; x deletes with confirmation
Alt+a, |                Split pane horizontally
Alt+a, -                Split pane vertically
Alt+a, r                Reload Tmux config
Alt+a, d                Detach from session
Alt+a, w                Show full session
Alt+a, [                Enter copy mode; y copies selection
Alt + h/j/k/l           Focus Tmux pane without prefix
Alt + Shift + h/j/k/l   Resize Tmux pane without prefix
Alt+a, Ctrl+s           Save session with Resurrect
Alt+a, Ctrl+r           Restore session with Resurrect
